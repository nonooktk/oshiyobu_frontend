## 3. 既存のテストの扱い

- **既存のテストの期待値・入力・skip の条件は、変えません**（G-24）。見た目を変えてテストが落ちたら、まず目印（`仕様.md` の 2 節）を消していないかを確かめます。目印を残しても落ちるときは、変えずに管理者へ聞きます。
- `tests/guard/` は、担当者には書き換えられません（設定で止めてあります）。
- 新しいテストは、新しいファイルで足します。

## 4. 担当者が足すテスト（新しいファイルで）

見た目の作り込みに合わせて、次を足します。置き場は `tests/integration/fan/`、名前は `look-*.test.tsx` を勧めます。

| 番号 | 確かめること | やり方の例 |
| --- | --- | --- |
| T-1 | 背景の段ごとに、ホームの見た目のクラス（または属性）が切り替わる | プランを上げて、`[data-plan-tier]` の値と、足したクラスを見る |
| T-2 | 素材を足した組・プランで、仮の表示ではなく、画像か動画が出る | `REWARD_MEDIA` に行を足した状態で、特典の層に `img` か `video` があり、「準備中」の文が無いことを見る |
| T-3 | 素材が無い組・プランでは、仮の表示のまま動く | 行が無い推しで、特典の層が開いて閉じられることを見る |
| T-4 | 作り込んだ層（参加の確認・プランを上げる・特典）の中に、札が 2 枚ある | 既存の `demo-notice.test.tsx` と同じ見方 |
| T-5 | 「動きを減らす」設定のとき、足した演出が出ない | `prefers-reduced-motion` をまねて、足した要素やクラスが無いことを見る |

## 5. 手で確かめること（PR の前に、担当者が）

条件: `npm run dev` で開いた `/fan/`。Chrome の、幅 390 × 高さ 844。V-8 では、幅 320・375 も見ます。

| 番号 | やること | 見えること |
| --- | --- | --- |
| V-1 | 推しを選んで「次へ」 | プランが 4 つ並ぶ。上の 3 つは、あるが選べないと分かる |
| V-2 | 「スタンダードプランで参加する」→ 確認で「もどる」→ もう一度進んで「参加する」 | 「もどる」では参加しない。「参加する」で、称賛が出てホームへ |
| V-3 | ホームを見る | 下のボタンは 1 つ。熱量は「FEVER 目前」。人数・割合の数字が無い |
| V-4 | 「預金でやることへ」→ 2 つを済ませる →「ホームへもどる」 | 済ませるたびに称賛。ホームの下のボタンが 2 つになる |
| V-5 | 「SNSで広める」→ X | 称賛が出る。外のサイトは開かない |
| V-6 | 「プランを上げる」→ ゴールド → プラチナ → ダイヤモンドの順に上げる | 上げるたびに、演出 → 特典 → 背景が 1 段豪華に。ダイヤモンドで「プランを上げる」が消える |
| V-7 | リセットして、いちばん下からダイヤモンドへ直接上げる | 1 回で上がる。背景は 3 段目。特典はダイヤモンドのもの |
| V-8 | 幅 320・375・390 でホームを見る（ボタンが 2 つの状態も） | スクロールなしで全部見える。横スクロールが出ない |
| V-9 | 確認・プランを上げるシート・演出・特典の層を開く | どれにも札が 2 枚ある |
| V-10 | 開発者ツールの通信の欄を見ながら、通しで進める | 自分の配信元の外への通信が 0 件 |
| V-11 | OS の「動きを減らす」をオンにして、V-6 をやる | 光・紙ふぶき・揺れが出ない |
| V-12 | `npm run verify` と `npm run e2e:solo` | どちらも合格 |

動画が届いたら、iPhone の Safari の実機で、画面の中で再生されること・音が鳴らないことを確かめます（テストの環境は、動画を再生しません）。
