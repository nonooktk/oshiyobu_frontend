# 仕様（ファン向けの画面。新しい流れ）

いまの土台がどう動くかと、担当者が作り込む所を、画面ごとに書きます。コードの事実は、`feat/fan-flow-v2`（2026-11-16）のものです。

## 1. 流れと状態

| 段 | 画面 | 状態（ストア） | 次へ進む操作 |
| --- | --- | --- | --- |
| A | はじめの画面 1/2（推しを選ぶ） | `page: 'start'`・`start.step: 0` | 「次へ」 |
| B | はじめの画面 2/2（プランの一覧） | `start.step: 1` | 「ベーシックプランで参加する」 |
| C | 参加の確認（シート） | 層 `confirm` | 「参加する」／「もどる」 |
| D | ホーム（預金でやることが残っている） | `course: 'normal'`・段階 `tasks` | 「預金でやることへ」 |
| E | 預金でやることのページ（口座と預金） | `page: 'acct'` | 2 つの行動 →「ホームへもどる」 |
| F | ホーム（済んだ） | 段階 `grow` | 「SNSで広める」／「プランを上げる」 |
| G | 投稿のシート | 層 `share` | X・Instagram・Facebook のどれか |
| H | プランを上げるシート | 層 `upgrade` | 「〜プランに上げる」 |
| I | 特別な演出 | 層 `fx`（種類 `upgrade`） | 自動で終わる |
| J | 特典の贈呈（シート） | 層 `reward` | 「閉じる」 |

- ホームの段階は、`homePhaseOf`（`src/fan/domain/plan.ts`）が決めます。`start` ＝ 参加していない、`tasks` ＝ 預金でやることが残っている、`grow` ＝ 済んだ、の 3 つです。
- 参加をやめたあとは、ホームの主のボタンが「参加するプランを選ぶ」になります。押すと B へ戻ります。

## 2. 画面ごとの中身と、作り込む所

「目印」は、テストが探している属性です。**目印は消さない・名前を変えない**でください。置く要素は、変えてかまいません。

### 2.1 プランの一覧（B）

- ファイル: `src/fan/components/Start.tsx`
- いまの中身: 4 つのプランが、名前・確保する額・特典つきで並ぶ。ベーシックだけが、選べるカード（白地・マゼンタの線・太い枠）。上の 3 つは、灰色に落として鍵の絵（`LockIcon`）を出し、「参加のあとに、上げられます」を添える（D-14）。
- 目印: `li[data-plan]` が 4 つ。上の 3 つは `aria-disabled="true"` と `data-locked="true"`（読み上げには、見えない文「（ロック中）」が付く）。ベーシックは `data-selected="true"`。**`li` の中にボタンを置かない**（選べないことを、テストが確かめている）。
- 作り込む所: カードの細かい見た目。色は、2.9 の区画で決める。

### 2.2 参加の確認（C）

- ファイル: `src/fan/components/PlanLayers.tsx` の `ConfirmSheet`
- いまの中身: 見出し「参加しますか？」、プランの名前、確保する額、「確認のための表示です。デモのため、実際の決済・入出金は行われません。」、ボタン 2 つ（「参加する」「もどる」）。
- 目印: `role="dialog"` の名前が「参加しますか？」。中身に `data-layer-body="confirm"`。
- 作り込む所: シートの見た目。「実際の決済は行われない」の一文は消さない。

### 2.3 ホーム（D・F）

- ファイル: `src/fan/components/Home.tsx`
- いまの中身: 推しの絵とひとこと、プランの名前の札と「特典を見る」、開催熱量、下のボタン。
- 目印: いちばん外の要素に `data-plan-tier`（0〜3）。主のボタンに `data-act`（`rejoin`・`tasks`・`share`）。2 つめのボタンに `data-act="upgrade"`。
- 作り込む所:
  - 背景。`.home[data-plan-tier='1']`〜`['3']`（`src/fan/fan.module.css` の末尾）に、段ごとの背景を書く。色は、2.9 の区画が決める（段 1 ＝ ゴールド・段 2 ＝ プラチナ・段 3 ＝ ダイヤモンド。上から薄く敷いて、下は `--bg-c` か `--surface` に抜ける）。背景の上に直接載る文字は、白い地を敷くか、背景の薄い所に置く。背景の絵が届いたら、ここで使う。
  - 下の 2 つのボタンの並び（`.homePair`）。幅 320 でも、スクロールなしで押せること。
  - プランの名前の札（`.planLine`・`.planChip`）。

### 2.4 預金でやることのページ（E）

- ファイル: `src/fan/pages/CoursesAcct.tsx` の `AcctPage`、`src/fan/pages/DepositCard.tsx`
- いまの中身: 上に「預金でやること」のカード（2 つの行動と、済んだかどうか）。下に、行動のカードが 2 つ。済むと「✓ すべて済みました」と「ホームへもどる」。
- 目印: カードに `data-tasks`（`todo`・`done`・`closed`）。行に `li[data-task]`（`teiki`・`deposit`）と `data-ok`。
- 作り込む所: やることの一覧の見た目（`.taskList`。`src/fan/pages/pages.module.css`）、済んだときの見せ方。

### 2.5 プランを上げるシート（H）

- ファイル: `src/fan/components/PlanLayers.tsx` の `UpgradeSheet`
- いまの中身: いまより上のプランが並ぶ。それぞれに、確保する額・特典・「〜プランに上げる」のボタン。
- 目印: `role="dialog"` の名前が「プランを上げる」。中身に `data-layer-body="upgrade"`。行に `li[data-plan]`。
- 見た目: シートが開けるのは、預金でやることが済んだあと（＝鍵が外れたあと）。並ぶのは、いまより上のプランだけなので、`data-locked` は付かず、2.9 のプランごとの色で出る。
- 作り込む所: プランごとの見た目の差（上のプランほど豪華に）。急がせる見せ方は入れない（G-05）。

### 2.6 特別な演出（I）

- ファイル: `src/fan/components/Layers.tsx` の `FxLayer`（種類 `upgrade`）、CSS は `src/fan/fan.module.css`
- いまの中身: 既存の強い演出と同じ見た目で、「プランアップ！」と称賛の文が出る。3 秒ほどで自動で終わる。
- 作り込む所: プランを上げたとき用の見た目。プランごとに強さを変えてもよい。「動きを減らす」設定のときは、光・紙ふぶき・揺れを出さない（既存の演出と同じ扱い）。
- 変えない所: 演出の長さ（ストアが時間で次へ進めている。変えたいときは相談）。

### 2.7 特典の贈呈（J）

- ファイル: `src/fan/components/PlanLayers.tsx` の `RewardSheet`、素材の対応は `src/fan/art/rewards.ts`
- いまの中身: 見出し「〜プランの特典」、「（推し）から、（特典）が届きました。」、枠（`.rewardFrame`）、「閉じる」。素材が無い間は、推しの絵と「（準備中の仮の表示）」。
- 目印: 中身に `data-layer-body="reward"` と `data-reward`（`image`・`video`）。
- 作り込む所: 枠の見た目、届いた感じの見せ方。素材の差し込みは 4 節。

### 2.8 メニューの下の画面

- ファイル: `src/fan/pages/`（プラン・口座と預金・貢献・支援の状況・しくみ・推しの変更・情報の扱い）
- 言い方と操作は、新しい流れにそろえてあります。見た目は、必要なら整える程度で、優先は低いです。
- 目印: プランのページに `li[data-plan]`（4 つ・中にボタン無し）。貢献のページに `[data-reward-row]`（3 つ）。
- プランのページ（`CoursesPage`）の鍵: 参加の前は、ベーシック以外の 3 つに `data-locked="true"`。参加したあとも、預金でやることが済む（ホームに「プランを上げる」が出る）までは、いまより上のプランに `data-locked="true"`。済むと外れて、プランの色で出る。いまのプランとそれより下は、鍵が付かない。

### 2.9 プランの色と鍵の見た目（D-14）

- 色を決める場所: `src/fan/fan.module.css` の「プランの色（ここ 1 か所で決める）」の区画。`data-plan`（`normal`・`front`・`special`・`top`）のカードと、ホームの `data-plan-tier`（0〜3。同じ順）が、同じ変数を引く。色の値は書かず、`tokens.css` の名前だけを使う。
- 変数: `--plan-a`・`--plan-b`（カードの地。左上 → 右下）、`--plan-line`（線）、`--plan-tag`・`--plan-tag-ink`（札 `.planChip` の地と文字）、`--plan-wash`・`--plan-wash-end`（ホームの背景の上と下）。

| プラン | 地（`--plan-a` → `--plan-b`） | 線 | 札の地 | ホームの背景（上 → 下） |
| --- | --- | --- | --- | --- |
| ベーシック（`normal`） | `--surface` → `--surface` | `--primary` | `--surface`（文字 `--primary-dark`） | そのまま（段 0） |
| ゴールド（`front`） | `--yellow-light` → `--yellow` | `--warning` | `--yellow`（文字 `--ink`） | `--yellow-light` → `--bg-c` |
| プラチナ（`special`） | `--surface` → `--line` | `--gray-300` | `--gray-300`（文字 `--ink`） | `--gray-300` → `--bg-c` |
| ダイヤモンド（`top`） | `--sky-light` → `--surface` | `--sky` | `--sky-light`（文字 `--ink`） | `--sky-light` → `--surface` |

- カードの文字は、どのプランも `--ink`。
- 鍵のかかった見た目: `li[data-locked='true']`（はじめの画面は `aria-disabled="true"` も）。プランの色は使わず、灰色（`--bg-c` の地・`--gray-300` の破線・`--ink-soft` の文字）に落として、鍵の絵（`src/fan/components/LockIcon.tsx`。インラインの SVG・`currentColor`・`aria-hidden`）を名前の前に出す。読み上げには、見えない文「（ロック中）」を付ける。
- 選んでいる・参加中のカード（`data-selected`・`data-mine`）は、線の色で太い枠（`box-shadow`）を足す。
- ホームの背景（段 1〜3）は、`--plan-wash` から下へ伸ばし、85% の位置で `--plan-wash-end` に抜ける。推しの絵の枠とセリフのカードの線は `--plan-line`。
- ホームの背景の上に直接載る文字は、背景のいちばん濃い所でも 4.5:1 以上にする。「特典を見る」には白い地（`--surface`）を敷き、メーターの上段（開催熱量・距離のことば）は `--ink` にする。
- 色つきのカード（`.planItem`）の中の塗りのボタンは、`--ink` の単色（文字 `--surface`。hover・押している間は `--ink-soft`）。副・文字のボタンと、カードの外のボタンは変えない。

## 3. 土台（変えるときは相談）

### 3.1 プランの決まり（`src/fan/domain/plan.ts`）

| 名前 | 中身 |
| --- | --- |
| `PLAN_ORDER` | プランの順（下から）: `normal`・`front`・`special`・`top` |
| `PLAN_NAMES` | 画面に出す名前: ベーシックプラン・ゴールドプラン・プラチナプラン・ダイヤモンドプラン |
| `ENTRY_PLAN` | 最初に参加するプラン（`normal`） |
| `upgradesOf(いまのプラン)` | いまより上のプランの一覧 |
| `rewardOf(プラン)` | 特典。`front` ＝ 画像、`special` ＝ 3 秒の動画、`top` ＝ 6 秒の動画 |
| `depositTasksOf` | 預金でやること 2 つと、済んだかどうか |
| `homePhaseOf` | ホームの段階（`start`・`tasks`・`grow`） |
| `backdropOf(プラン)` | 背景の段（0〜3） |

金額と預金の条件は、core が計算します（画面に数字を直接書かない。G-17）。

### 3.2 ストアの操作（`src/fan/store/store.ts`。画面からは `useFan().actions`）

| 操作 | 動き |
| --- | --- |
| `openJoinConfirm`／`closeJoinConfirm` | 参加の確認を開く／閉じる |
| `joinPlan` | 参加する（いちばん下のプラン）。称賛の演出と音 |
| `goTasks` | 預金でやることのページへ |
| `runAcct('teiki', …)`・預金の入力 | 預金でやることを済ませる |
| `openShare('share')` | 投稿のシートを開く |
| `openUpgrade`／`closeUpgrade` | プランを上げるシートを開く／閉じる |
| `upgradePlan(プラン)` | プランを上げる。演出 → 特典の贈呈 |
| `showReward`／`closeReward` | いまのプランの特典を見る／閉じる |
| `rejoin` | 参加していないとき、プランの一覧へ戻る |

### 3.3 熱量・音・称賛

- 熱量は、`src/fan/domain/heat.ts` の `SOLO_FILL = 0.8` で固定です。段階の名前は「FEVER 目前」。行動しても動きません。
- 音は、参加したとき（`join`）・SNS で初めて広めたとき（`friend`）・プランを上げたとき（`fever`）に、音源ファイルが鳴ります。ほかは合成の音です。
- 称賛の文は、`src/fan/text/praise.ts` にあります。形は「あなたがしたこと → それで何が進んだか」。褒めるのは行動だけです（G-04）。

## 4. 素材の置き場と差し込み方

| 素材 | 置き場 | 形式・上限 |
| --- | --- | --- |
| 追加の画像（ゴールド） | 推しの絵と同じやり方（`src/assets/img/`・`assets-src/`。変えたら `npm run images`。`docs/守ること.md` の 1 節） | WebP。量の検査の上限の中 |
| 3 秒の動画（プラチナ）・6 秒の動画（ダイヤモンド） | `public/rewards/` | MP4 か WebM。1 本 4 MB・合計 5 MB まで。音なし |
| 背景の絵（3 段） | 推しの絵と同じやり方 | WebP |

差し込みは、`src/fan/art/rewards.ts` の `REWARD_MEDIA` に 1 行足すだけです。

```ts
export const REWARD_MEDIA = {
  tech0: {
    // goldImageUrl は、推しの絵と同じように、ファイルの先頭で import した WebP
    front: { src: goldImageUrl, alt: 'Tech0サステナアイドルの追加の画像' },
    special: { src: '/rewards/tech0-platinum.mp4', alt: 'Tech0サステナアイドルの3秒の動画' },
    top: { src: '/rewards/tech0-diamond.mp4', alt: 'Tech0サステナアイドルの6秒の動画' },
  },
};
```

- 行が無い組・プランは、仮の表示になります。1 組ぶんだけ届いても、そのまま動きます。
- `src` に、外の URL（`http://`・`https://`・`//`）は書けません（検査で落ちます）。
- `<video>` には `muted` と `playsInline` が要ります（いまの `RewardSheet` に付いています。外すと検査で落ちます）。
- 素材は、自作か CC0 のものだけです（リポジトリが公開のため）。出どころが分からない素材は、置かずに管理者へ聞きます。

## 5. 画面の大きさ

- 基準は、幅 390 × 高さ 844。幅 320・375 でも、横スクロールが出ないこと。
- ホームは、下のボタンが 2 つの状態でも、スクロールなしで全部が見えること。
- ボタンの高さは 44px 以上。
