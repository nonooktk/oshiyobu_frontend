## 2. 用語

| 語 | 意味 |
| --- | --- |
| プラン | ファンが選ぶ 4 つの段。core のコース（`normal`・`front`・`special`・`top`）に、下から順に当てる |
| 参加 | いちばん下のプランを選び、確認で「参加する」を押すこと |
| 預金でやること | 参加のあとに済ませる 2 つ（推し活定期をはじめる・預金を積み増す） |
| 特典 | プランを上げると届くもの（追加の画像・3 秒の動画・6 秒の動画） |
| 背景の段 | ホームの背景の豪華さ。0（いちばん下・未参加）〜3（ダイヤモンド） |
| 札 | 「動作確認用のデモ画面です」と「デモ用の架空データ」の 2 枚 |
| 土台 | 流れと状態の骨組み（`src/fan/store/`・`src/fan/domain/`）。管理者が持つ |

## 4. 今回作らないもの

- 実際の決済・入出金・本人確認・ログイン。
- 実際の SNS への投稿と、外のサイトへの移動（G-06）。
- 事務所向け（`src/office/`）・発表者用（`src/presenter/`）・共通の部品（`src/shared/`）の変更。
- core の変更（G-17）。
- 新しい音源ファイル（G-04）。
- 外部からの動画の読み込み（G-16）。
- プランを下げる動き。やめるときは、メニューの「参加をやめる」だけ。
- 人数・割合・達成率・目標の金額の表示（G-08）。

## 5. 見た目を作るときも、満たしたままにすること

番号と中身は `docs/守ること.md` が正本です。

- G-05: 急がせる促し（点滅・残り時間・「いますぐ」）を入れない。「プランを上げる」の誘いにも入れない。
- G-08: 人数・割合・達成率・目標の金額の数字を出さない（「80%」も出さない）。出してよいのは、金額・席数・特典の動画の長さなど、決まりに書いてあるものだけ。
- G-09: 札 2 枚を、どの画面・シート・演出・動画の上でも消さない。
- G-10: 「新しい口座を開く」「口座開設」「確約」を使わない。賭け・運・得を連想させる語と絵と音を入れない。
- G-11・G-12・G-14: 書体・文字の大きさ・色の決まり。
- G-15・G-16: 絵は WebP。動画は 1 本 4 MB・合計 5 MB まで。外から読み込まない。
- G-28: ホームで押す場所は、主のボタンだけ（預金でやることが済んだあとは 2 つ）。
