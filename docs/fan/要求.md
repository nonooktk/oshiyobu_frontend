# 要求（ファン向けの画面。新しい流れ）

何のために、何を変えるのかを書きます。

## 1. 原文（統括の指示）

次の枠の中は、原文のままです。

```
デモでやりたいこと
・ファンの以下二つの行動をエンハンスするアプリであることを伝える
・SNSでの拡散
・上位プランへの重課金（と、それに応じた報酬の入手）

フロー
1 推しを選ぶ
2 最安の参加プランを選ぶ（他はロックされている）→選ぶとプロジェクトに参加、いったん事前収集のための決済が発生する故、参加前にポップアップで参加しますか？といったリマインド表示が出るイメージ
3 プロジェクトに参加してホーム画面
4 預金関連の条件が満たされていないので、それを下部ボタンで促す→押すと預金関連でやることページに飛ぶ→達成できたらそれぞれファンファーレ
5 4が終わるとホーム画面上の下部ボタン部にSNSで広めるを推奨するものと、上位プランへのアップグレードへの誘いが出る。上位プランは、ゴールドプラン、ダイヤモンドプラン、プラチナプラン。
6 SNSで広めたらファンファーレ。上位プランに移行したら特殊エフェクトとその他記載アイテム贈呈。

その他
・ゴールドプラン、ダイヤモンドプラン、プラチナプランと、ステータスが上がることでホーム画面の背景もプランに応じた豪華さになっていく
・ゴールドプランでは追加画像、ダイヤモンドプランで5秒動画、プラチナプランで20秒動画贈呈。従来の、アクションするたびに解除されていく画像の部分をこれに置き換える。
・ゴールドプラン、ダイヤモンドプラン、プラチナプランは最初は選べないが、存在は示す。画像部分はなくて良い。
・1ユーザーのシーン切り取りなので、イベント開催熱量ゲージは80%ぐらいでステイしていて良い
```

あとから決まったことは、`要件.md` の 1 節にまとめました。上位プランの順は「ゴールド → プラチナ → ダイヤモンド」に変わり、動画の長さは、2026-11-16 に、プラチナが 3 秒、ダイヤモンドが 6 秒に変わりました（理由は `要件.md` の D-3）。

## 2. 誰が・どの場面で・何のために使うか

| 項目 | 内容 |
| --- | --- |
| 誰が | ファン（推しを応援する人）。自分のスマホで、最後まで体験する |
| 誰に見せるか | 発表の聞き手。発表者が画面を見せるか、聞き手が自分のスマホで触る |
| どの場面で | 発表のデモ（2026-11-20）。1 人のファンの、ある場面だけを切り取った体験 |
| 何のために | ファンの 2 つの行動を、アプリが後押しすると伝えるため。1 つめは SNS で広めること、2 つめはプランを上げて特典を受け取ること |

## 3. 要求の一覧

| 番号 | 要求 |
| --- | --- |
| Q-01 | 推しを選び、いちばん下のプランで参加できる。上の 3 つのプランは、最初は選べないが、あることは分かる |
| Q-02 | 参加の前に、「参加しますか？」の確認が出る。確認は表示だけで、実際の支払いは起きない |
| Q-03 | 参加のあと、預金でやることを、ホームの下のボタンから進められる。済ませるたびに、称賛が出る |
| Q-04 | 預金でやることが済むと、ホームの下に「SNSで広める」と「プランを上げる」が出る |
| Q-05 | SNS で広めると、称賛が出る |
| Q-06 | プランを上げると、特別な演出が出て、特典（追加の画像・3秒の動画・6秒の動画）が届く |
| Q-07 | プランが上がるほど、ホームの背景が豪華になる |
| Q-08 | 開催熱量のゲージは、8 割ほどの位置で動かない |

## 4. うまくいった状態

発表者が、スマホの画面を 1 分ほど操作するだけで、聞き手に「SNS で広めると褒められる」「プランを上げると、背景が変わって特典が届く」の 2 つが伝わること。途中で止まらず、説明なしで次に押す所が分かること。
