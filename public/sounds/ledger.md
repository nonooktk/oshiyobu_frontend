# 音源の台帳（G-04）

ファン向けの称賛の音のうち、**申し込んだ瞬間（join）・仲間を呼んだ瞬間（friend）・最後の演出＝開催決定（fever）の 3 場面だけ**、音源ファイルに差し替えます。ほかの場面の音（推し活定期をはじめたとき・預金が条件に届いたとき・SNS への投稿など）は、`src/fan/sound.ts` の合成のままです。

このフォルダ（`public/sounds/`）が、音声ファイルの**唯一の置き場**です。ここに置いてよいのは、下の表に書いたファイルだけです（`tests/guard/sound-files.test.ts` が見張ります）。

- 出どころ（URL）・作者・ライセンス・確認日が、すべて書いてある。ライセンスは **CC0** か **自作** だけ（ほかのライセンスは、決まりの更新が先に要る）。
- 場面は join・friend・fever のどれか。1 つの場面に、ファイルは 1 つ。
- 賭けを連想させる音（スロット・硬貨・くじ・ドラムロール・金属音・ジャラジャラなど）は、ファイルにも入れません。表の「どんな音」に、耳で確かめた中身を書きます。
- 形式は MP3（iOS の Safari は ogg を再生できないため）。1 ファイル 60 KB 以下、3 ファイルの合計 180 KB 以下（`npm run check:budget` が見ます）。
- **元の WAV など、配らないファイルは、このリポジトリに入れません。**

## 変換のしかた（再現できます）

ffmpeg（libmp3lame つき。確かめた版は 9.0.1）で、元の WAV から配る MP3 を作ります。命令の入力は、台帳に書いた元の WAV です（Freesound の名前のまま、WAV のあるフォルダで実行する）。同じ命令で、同じバイト列になります（B は、別のフォルダで作り直して、SHA-256 が同じことを確かめた）。

### A-join.mp3（場面 join）

残響が自然に消える所（音量が、いちばん大きい所より約 40 dB 小さくなる 2.2 秒）で切り、ぶつ切りにしない。

```
ffmpeg -y -i 878622__qvantor__secret-found.wav -t 2.2 \
  -af "volume=6.5dB,afade=t=out:st=1.7:d=0.5" \
  -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 \
  -map_metadata -1 -id3v2_version 0 -write_id3v1 0 A-join.mp3
```

### B-friend.mp3（場面 friend）

拍手が立ち上がって広がる所を使う（人が集まってくる感じを出すため）。元の録音は、0.5 秒ごろまでほぼ無音（0.1 秒ごとの RMS で -47〜-53 dBFS）で、1 秒ごとに大きくなり、3 秒ごろに -16 dBFS 前後へ届く。

- **切り出しの開始**: 0.9 秒。拍手が、押した瞬間から聞こえるようにする。開始の候補ごとに、冒頭の 0.1 秒の音量が、切った区間でいちばん大きい 0.1 秒の音量より何 dB 小さいかを測った。0.9 秒が 16.7 dB・0.8 秒が 17.6 dB・0.7 秒が 24.6 dB・0.6 秒が 28.0 dB。0.6 秒（ほぼ無音から立ち上がる版）と 0.9 秒（冒頭の -32 dBFS から拍手が聞こえる版）を作って聞き比べ、頭から聞こえる 0.9 秒に決めた（2026-11-15）。
- **長さとフェード**: 2.5 秒。頭に 0.03 秒のフェードイン（クリックノイズの防止）。1.9 秒から 0.6 秒かけてフェードアウトする（最後の演出 fever と重なるとき、重なる音量を小さくするため。重なりは、下の C の節）。

```
ffmpeg -y -ss 0.9 -i 634524__salsero_classic__aplaudiments-applause.wav -t 2.5 \
  -af "volume=2.60dB,afade=t=in:st=0:d=0.03,afade=t=out:st=1.9:d=0.6" \
  -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 \
  -map_metadata -1 -id3v2_version 0 -write_id3v1 0 B-friend.mp3
```

**最後の演出（fever）との重なり**: C を足す前は、合成の fever との重なりを見積もっていた。C（ファイル）を足したので、見直した。数値は、下の C の節の「重なり」。

### C-fever.mp3（場面 fever）

最後の演出（開催決定）は、いちばん派手な場面。金管のファンファーレに、観客の音を重ねる（統括の指示 2026-11-15: 「C はこれに歓声を合わせて欲しい」）。入力は 2 つ。ファンファーレ（FunWithSound。MP3）と、観客（B と同じ元の録音。B は立ち上がる所の 0.9〜3.4 秒を使い、C は、盛り上がりが続く所を使う）。命令の 1 つめの入力が、ファンファーレの MP3、2 つめが、観客の WAV。

- **ファンファーレ**: 頭から使う。音があるのは約 3.1 秒まで（0.1 秒ごとの RMS で、0.7〜2.4 秒が -17.6〜-20.2 dBFS。2.5 秒から小さくなり、3.1 秒より先は -50 dBFS 以下）。長さは、最後の演出（3.6 秒。`src/fan/store/store.ts` の `showReached`）と同じ 3.6 秒にする。
- **観客の区間**: 元の 10.4 秒から 3.6 秒間（10.4〜14.0 秒）。元の録音は 10〜13 秒ごろがいちばん大きい（0.1 秒ごとの RMS で -12.6〜-15.5 dBFS）。開始を 9.0〜12.4 秒で 0.1 秒ずつ動かし、混ぜた音で観客のフェードアウトが始まる前の 2.8 秒間について、① 0.1 秒ごとの RMS の最大と最小の差（小さいほど、区間の中で落ちない）② 0.3 秒の平均で見た、0.1 秒あたりの最大の落ち込み、を比べた。10.3〜10.6 秒開始が、差 2.8 dB でいちばん小さく、落ち込みは 0.4 dB 以下（9.0〜9.7 秒開始は 3.5〜4.1 dB、10.9 秒開始以降は 3.1〜3.5 dB）。10.4 秒にしたのは、いちばん大きい所（元の 11.3〜12.8 秒。-12.6〜-14.1 dBFS）が、混ぜた音の 0.9〜2.4 秒（ファンファーレの強い所）に重なるため。元の 12.9 秒で 1 段下がる所（-15.0 dBFS）は、混ぜた音の 2.5 秒ごろで、ファンファーレも小さくなり始める所。
- **混ぜ方**: 観客を、ファンファーレの頭（0 秒）と同時に入れる。頭に 0.15 秒のフェードイン、ファンファーレが小さくなったあとも残して、2.8 秒から 0.8 秒かけてフェードアウト。ファンファーレは、長さと音量以外、触らない。音量は、観客の 0〜3 秒の RMS が、ファンファーレの 0〜3 秒の RMS より **6.0 dB 小さい**ように決め（ファンファーレが主役）、足し合わせた音のピークが、MP3 にしたあと -1 dBFS 前後（-1.09 dBFS）になるように、2 つを同じだけ上げた（ファンファーレ +3.62 dB・観客 -8.87 dB。音をつぶす処理〈リミッターなど〉は使わない）。
- **同じ命令で、同じバイト列**: 別のフォルダで 2 回作り直して、SHA-256 が同じことを確かめた（99256b70e1724046d88bec0b5f1ef3bed24ca7473c1e1f5615a60ecd1d8c20ab）。

```
ffmpeg -y -i 456966__funwithsound__success-fanfare-trumpets.mp3 \
  -ss 10.4 -t 3.6 -i 634524__salsero_classic__aplaudiments-applause.wav \
  -filter_complex "[0:a]atrim=0:3.6,asetpts=PTS-STARTPTS,volume=3.62dB[f];[1:a]asetpts=PTS-STARTPTS,volume=-8.87dB,afade=t=in:st=0:d=0.15,afade=t=out:st=2.8:d=0.8[c];[f][c]amix=inputs=2:duration=longest:normalize=0" \
  -t 3.6 -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 \
  -map_metadata -1 -id3v2_version 0 -write_id3v1 0 C-fever.mp3
```

**重なり**（`src/fan/store/store.ts`。MP3 を復号して、gain をかけた出力を 0.1 秒ごとに測った値。耳では確かめていない）:

- **B → C（仲間を呼んで成立する流れ。`callFriends`）**: B が鳴り始めてから C が鳴るまでは、通常 2.6 秒・「動きを減らす」設定では 1.8 秒。C は、止めない・遅らせない（最後の演出を無音にしない）。通常は、B（2.5 秒）が鳴り終わった 0.1 秒後なので、重ならない。「動きを減らす」設定では 0.7 秒重なる。重なる 0.7 秒の 0.1 秒ごとに、C が B より何 dB 大きいかは、-5.0・-5.1・-4.4・-0.3・+3.9・+9.6・+19.6 dB（C の頭は、ファンファーレの最初の短い音と、そのあとの小さな間なので、B のほうが大きく、B が小さくなるにつれて C が上回る）。重なる 0.7 秒の全体では、B が -38.0 dBFS・C が -37.9 dBFS で、差は 0.0 dB。2 つを足したピークは -21.5 dBFS で、割れない。
- **A → C（申し込みで成立する流れ。共有メーターありで、サーバーの人数が、あと 1 人で届く所にいたときだけ起きうる）**: A が鳴り始めてから C が鳴るまでは、通常 0.65 秒・「動きを減らす」設定ではほぼ 0 秒。通常は、A の残り 1.55 秒と重なり、A が -44.2 dBFS・C が -34.6 dBFS（C が 9.6 dB 大きい）。「動きを減らす」設定では、A の全体（2.2 秒）と重なり、A が -38.0 dBFS・C が -34.2 dBFS（C が 3.8 dB 大きい）。ただし最初の 0.6 秒は、A（駆け上がり）のほうが、C より 2.9〜8.0 dB 大きい。
- **C が鳴っている間（3.6 秒）の、ほかの合成の音**: 段階が上がる音（stage）・行動の音（share）は、重ねない（`HELD_BACK_BY_FILE`。ファイルの音が鳴っている間は、鳴らさない）。成立の演出（層）が出ている間は、下の画面を押せない。層を閉じたあとに、続けて押したときだけ、鳴りうる。join（やめる → 申し込み直し）を 3.6 秒のうちに起こすには、層を閉じて 2 つ操作する必要があり、起こりにくい（見立て）。friend は、呼べるのが 1 回だけで、成立の前にしか鳴らない。
- **演出の長さとの関係**: 最後の演出は、通常 3.6 秒で自動で閉じる（C と同じ長さ）。「動きを減らす」設定では 2.0 秒で閉じ、C は 3.6 秒のまま鳴り続け、次の特典の演出（2.0〜3.5 秒）に重なる。演出を、タップ・Esc で先に閉じても、C は止まらない（A・B と同じ。止まるのは、音のボタンでオフにしたとき）。

### 音量（volume と gain）の決め方

- **volume**: 元のピークが -1 dBFS 前後になるように決めます（変換後の MP3 を復号して、サンプルのピークを測る）。MP3 にすると、ピークは 0.5〜0.8 dB ほどばらつく（B は volume を 2.40〜2.90 dB で動かすと -2.09〜-1.34 dBFS）ので、0 dBFS を超えない値を選ぶ。B の +2.60 dB は、ピークが -1.44 dBFS（-1 dBFS 前後より 0.44 dB 低い）。volume を上げると RMS と gain が変わり、聞き比べて決めた音と違ってしまうので、+2.60 dB のままにした。切る長さとフェードの始まりは、音量の移り変わりを見て決めます。
- **gain**（`src/fan/sound-files.ts` の対応表）: 聞こえる大きさをそろえるため、**変換後の MP3 を復号した全長の RMS（ステレオ全体）を、A にそろえる**。A の RMS は -18.86 dBFS（gain 0.11）、B は -17.59 dBFS。B のほうが 1.27 dB 大きい（拍手は雑音に近く、ピークが同じでも平均が大きい）。B の gain は、0.11 × 10^(-1.272 / 20) ＝ 0.0950 → **0.095**。gain をかけた出力の RMS は、A が -38.03 dBFS・B が -38.03 dBFS。
- **C の gain**: 最後の演出は、いちばん派手な場面なので、A・B より、出力の RMS を 2〜3 dB 大きくしてよい（統括の指示を受けたコーディネーターの決め）。C の RMS は -17.17 dBFS（A より 1.69 dB 大きい。ピークは -1.09 dBFS）。A にそろえる gain は、0.11 × 10^(-1.69 / 20) ＝ 0.0906。ここから +2.5 dB 大きくする gain は、0.0906 × 10^(2.5 / 20) ＝ 0.121 で、検査の上限（0.12。`tests/unit/fan/sound-files.test.ts`）を、わずかに超える。そのため、上限の **0.12** にした。gain をかけた出力の RMS は -35.59 dBFS で、A・B より 2.44 dB 大きい。ピークは -19.5 dBFS（A は -20.2・B は -21.9）。

## 音を足すとき（A・B・C は、この手順で足した。3 場面とも、ファイルになった）

1. 変換した MP3 を、このフォルダに置く（名前は `B-friend.mp3`・`C-fever.mp3` のように、場面が分かる名前。差し替えるときは、名前を変える。配信のキャッシュが残るため）。
2. 上の表に 1 行足す（9 つの欄をすべて埋める）。
3. `src/fan/sound-files.ts` の対応表に 1 行足す（場面 → ファイル・音量）。

`npm run verify` が通れば、足せています。ファイルが読めないあいだは、合成の音が鳴ります。
