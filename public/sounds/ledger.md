# 音源の台帳（G-04）

ファン向けの称賛の音のうち、**申し込んだ瞬間（join）・仲間を呼んだ瞬間（friend）・最後の演出＝開催決定（fever）の 3 場面だけ**、音源ファイルに差し替えます。ほかの場面の音（推し活定期をはじめたとき・預金が条件に届いたとき・SNS への投稿など）は、`src/fan/sound.ts` の合成のままです。

このフォルダ（`public/sounds/`）が、音声ファイルの**唯一の置き場**です。ここに置いてよいのは、下の表に書いたファイルだけです（`tests/guard/sound-files.test.ts` が見張ります）。

- 出どころ（URL）・作者・ライセンス・確認日が、すべて書いてある。ライセンスは **CC0** か **自作** だけ（ほかのライセンスは、決まりの更新が先に要る）。
- 場面は join・friend・fever のどれか。1 つの場面に、ファイルは 1 つ。
- 賭けを連想させる音（スロット・硬貨・くじ・ドラムロール・金属音・ジャラジャラなど）は、ファイルにも入れません。表の「どんな音」に、耳で確かめた中身を書きます。
- 形式は MP3（iOS の Safari は ogg を再生できないため）。1 ファイル 60 KB 以下、3 ファイルの合計 180 KB 以下（`npm run check:budget` が見ます）。
- **元の WAV など、配らないファイルは、このリポジトリに入れません。**

## 変換のしかた（再現できます）

ffmpeg（libmp3lame つき。確かめた版は 9.0.1）で、元の WAV から配る MP3 を作ります。命令の入力は、台帳に書いた元の WAV です（Freesound の名前のまま、WAV のあるフォルダで実行する）。同じ命令で、同じバイト列になります（B は、別のフォルダで作り直して、SHA-256 が同じことを確かめた）。

### A-join.mp3（場面 join）

残響が自然に消える所（音量が、いちばん大きい所より約 40 dB 小さくなる 2.2 秒）で切り、ぶつ切りにしない。

```
ffmpeg -y -i 878622__qvantor__secret-found.wav -t 2.2 \
  -af "volume=6.5dB,afade=t=out:st=1.7:d=0.5" \
  -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 \
  -map_metadata -1 -id3v2_version 0 -write_id3v1 0 A-join.mp3
```

### B-friend.mp3（場面 friend）

拍手が立ち上がって広がる所を使う（人が集まってくる感じを出すため）。元の録音は、0.5 秒ごろまでほぼ無音（0.1 秒ごとの RMS で -47〜-53 dBFS）で、1 秒ごとに大きくなり、3 秒ごろに -16 dBFS 前後へ届く。

- **切り出しの開始**: 0.9 秒。拍手が、押した瞬間から聞こえるようにする。開始の候補ごとに、冒頭の 0.1 秒の音量が、切った区間でいちばん大きい 0.1 秒の音量より何 dB 小さいかを測った。0.9 秒が 16.7 dB・0.8 秒が 17.6 dB・0.7 秒が 24.6 dB・0.6 秒が 28.0 dB。0.6 秒（ほぼ無音から立ち上がる版）と 0.9 秒（冒頭の -32 dBFS から拍手が聞こえる版）を作って聞き比べ、頭から聞こえる 0.9 秒に決めた（2026-11-15）。
- **長さとフェード**: 2.5 秒。頭に 0.03 秒のフェードイン（クリックノイズの防止）。1.9 秒から 0.6 秒かけてフェードアウトする（最後の演出 fever の合成と重なるとき、重なる音量を小さくするため。重なりは下）。

```
ffmpeg -y -ss 0.9 -i 634524__salsero_classic__aplaudiments-applause.wav -t 2.5 \
  -af "volume=2.60dB,afade=t=in:st=0:d=0.03,afade=t=out:st=1.9:d=0.6" \
  -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 \
  -map_metadata -1 -id3v2_version 0 -write_id3v1 0 B-friend.mp3
```

**最後の演出（fever。いまは合成）との重なり**（`src/fan/store/store.ts` の `callFriends`。計算で見積もった値で、耳では確かめていない）:

- 仲間を呼んだ（B が鳴り始める）あと、fever は **2.6 秒後**（「動きを減らす」設定では **1.8 秒後**）に鳴る。fever は、B が鳴っていても止めない（最後の演出を無音にしない）。
- 通常は、B（2.5 秒）が鳴り終わった 0.1 秒後なので、重ならない。「動きを減らす」設定では 0.7 秒重なる（うち、B のフェードアウトと 0.6 秒）。fever の頭の 2 音は、B と同じくらいの大きさ（fever のほうが 0.7〜2.2 dB 大きい）で、3 音目は 4.6 dB、4 音目からは B が小さくなって fever が 7.8 dB 以上大きい。重なっている 0.7 秒の全体では、fever のほうが 4.9 dB 大きい。
- C（fever）のファイルを足すときは、この重なりを見直す。

### 音量（volume と gain）の決め方

- **volume**: 元のピークが -1 dBFS 前後になるように決めます（変換後の MP3 を復号して、サンプルのピークを測る）。MP3 にすると、ピークは 0.5〜0.8 dB ほどばらつく（B は volume を 2.40〜2.90 dB で動かすと -2.09〜-1.34 dBFS）ので、0 dBFS を超えない値を選ぶ。B の +2.60 dB は、ピークが -1.44 dBFS（-1 dBFS 前後より 0.44 dB 低い）。volume を上げると RMS と gain が変わり、聞き比べて決めた音と違ってしまうので、+2.60 dB のままにした。切る長さとフェードの始まりは、音量の移り変わりを見て決めます。
- **gain**（`src/fan/sound-files.ts` の対応表）: 聞こえる大きさをそろえるため、**変換後の MP3 を復号した全長の RMS（ステレオ全体）を、A にそろえる**。A の RMS は -18.86 dBFS（gain 0.11）、B は -17.59 dBFS。B のほうが 1.27 dB 大きい（拍手は雑音に近く、ピークが同じでも平均が大きい）。B の gain は、0.11 × 10^(-1.272 / 20) ＝ 0.0950 → **0.095**。gain をかけた出力の RMS は、A が -38.03 dBFS・B が -38.03 dBFS。

## 音を足すとき（C。場面 fever。B〈friend〉も、この手順で足した）

1. 変換した MP3 を、このフォルダに置く（名前は `B-friend.mp3`・`C-fever.mp3` のように、場面が分かる名前。差し替えるときは、名前を変える。配信のキャッシュが残るため）。
2. 上の表に 1 行足す（9 つの欄をすべて埋める）。
3. `src/fan/sound-files.ts` の対応表に 1 行足す（場面 → ファイル・音量）。

`npm run verify` が通れば、足せています。ファイルが読めないあいだは、合成の音が鳴ります。
