# src/ の構成と持ち主

フォルダごとに持ち主（レーン）が決まっています。同じファイルを複数の人が触らないための決まりです（設計 D-35）。
自分のフォルダの外を直したいときは、直さずに、コーディネーターに頼んでください。

| フォルダ | 中身 | 持ち主 | 触るときの決まり |
| --- | --- | --- | --- |
| `shared/` | 3 ページ共通の部品・通信・連動・先読み | F-0 の担当（F-2 の担当へ引き継ぐ。引き継ぎはコーディネーターが指示する） | F-1・F-3 が変更を要るときは、コーディネーター経由 |
| `styles/` | `tokens.css`（色・間隔・書体）と `base.css`（全ページ共通の土台） | 同上 | 新しい色を足さない。値は `var(--名前)` で使う |
| `office/` | 事務所向け（`/`） | F-1 | `text/` は文言。`components/` は部品 |
| `presenter/` | 発表者用（`/presenter/`） | F-1 | 聞き手の画面からリンクしない |
| `fan/` | ファン向け（`/fan/`。QR の行き先） | F-2 | `text/` は文言（セリフ・感謝の文を含む） |
| `core/` | backend の core（計算とデータ）の写し | 手で直さない | backend で直し、`core:sync` で置く（F-0b で作る。今は空） |
| `assets/img/` | 配信用の絵（表示の大きさに縮めた WebP） | F-3 | 元絵は、リポジトリ直下の `assets-src/`（配信しない） |

## 今あるもの

- `shared/mount.tsx`: 3 ページの入り口の共通処理。各ページの `main.tsx` は、これを呼ぶだけ
- `shared/components/DemoBadge`: 札「デモ用の架空データ」。全画面に出す。消さない
- 各ページの `App.tsx`: 枠だけ（見出しと札とロゴ）。中身は、持ち主のレーンが作る

## 次の担当（F-0b・F-1・F-2）へ

各フォルダの `README.md` に、置くものと決まりを書きました。
