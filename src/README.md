# src/ の構成と持ち主

フォルダごとに持ち主（レーン）が決まっています。同じファイルを複数の人が触らないための決まりです（設計 D-35）。
自分のフォルダの外を直したいときは、直さずに、コーディネーターに頼んでください。

| フォルダ | 中身 | 持ち主 | 触るときの決まり |
| --- | --- | --- | --- |
| `shared/` | 3 ページ共通の部品・通信・連動・先読み | F-0 の担当（F-2 の担当へ引き継ぐ。引き継ぎはコーディネーターが指示する） | F-1・F-3 が変更を要るときは、コーディネーター経由 |
| `styles/` | `tokens.css`（色・間隔・書体）と `base.css`（全ページ共通の土台） | 同上 | 新しい色を足さない。値は `var(--名前)` で使う |
| `office/` | 事務所向け（`/`） | F-1（作り直しを担当者へ渡す準備中） | `text/` は文言。`components/` は部品。実在のデータは `office/data/` |
| `office/data/` | 事務所向け専用の、実在のデータ（会場・過去の公演）の置き場 | 事務所向けの担当者（置き場と検査は管理者） | 出典の URL と確認日を付ける。個人の情報を入れない。計算に使わない（G-30。`office/data/README.md`） |
| `presenter/` | 発表者用（`/presenter/`） | F-1 | 聞き手の画面からリンクしない |
| `fan/` | ファン向け（`/fan/`。QR の行き先） | F-2 | `text/` は文言（セリフ・感謝の文を含む） |
| `core/` | backend の core（計算とデータ）の写し | 手で直さない | backend で直し、`core:sync` で置く（置いてある版は `core.lock.json`） |
| `assets/img/` | 配信用の絵（表示の大きさに縮めた WebP） | F-3 | 元絵は、リポジトリ直下の `assets-src/`（配信しない） |

## 今あるもの

- `shared/mount.tsx`: 3 ページの入り口の共通処理。各ページの `main.tsx` は、これを呼ぶだけ
- `shared/components/DemoBadge`: 札「動作確認用のデモ画面です」と札「デモ用の架空データ」。全画面に出す。消さない
- 各ページの `App.tsx`: ページの組み立て。中身は、持ち主のフォルダにある

## 決まり

各フォルダの `README.md` に、置くものと決まりを書いています。番号つきの決まり（G-01 から）と、変えてよい所・変えてはいけない所は、`docs/守ること.md` が正本です。
