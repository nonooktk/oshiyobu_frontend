# src/fan/

ファン向け（`/fan/`。QR の行き先）。持ち主は F-2 です。人物（端末の番号から決まる 15 通り）の初めの値で、はじめの画面から始まります。

## 構成

| 場所 | 中身 |
| --- | --- |
| `App.tsx` | 殻。ページの切り替え・重ねる層・トースト・読み上げの領域・Esc。メニュー配下の画面と層は、`ChunkBoundary` で遅れて読む |
| `store/store.ts` | ストア（React の外に 1 つ）。状態と、申し込み・80% の演出・特典・感謝・共有・リセットの**順番**（タイマー）を持つ。通信はしない（`joinPerformance` を呼ぶだけ） |
| `store/FanProvider.tsx` | ストアと共有の部品（条件・共有メーター・連動）をつなぐ。reset の検知・「デモを最初に戻す」の受け口もここ |
| `domain/` | `state.ts`（状態の型と初めの値）・`view.ts`（人数・成立・次のアクションなど、画面が使う値）・`share.ts`（投稿文と共有の URL）。数字・成立の判定は **core の関数だけ**を使う |
| `components/` | 最初に読む画面（はじめの画面・ホーム・メーター・次のアクション・演出・特典・感謝・共有のシート・絵の部品） |
| `pages/` | あとから読む画面（メニュー・応援コース・口座と預金・貢献・支援の状況・しくみ・推しと条件の変更・情報の扱い。設計 D-40 の `fan-pages`） |
| `layers/` | あとから読む層（やめる確認・引き継ぎ。`fan-layers`） |
| `art/registry.ts` | 推しの絵の置き場（1 か所）。丸い絵・大きい絵・コースのカードの切り抜き・特典の切り抜き。先読みの登録もここ |
| `prefetch.ts` | 先読みする絵と、遅れて読む塊を、共有の部品（`src/shared/prefetch.tsx`）に登録する |
| `text/` | 画面の文言。`voices.ts`（5 組のセリフ）・`thanks.ts`（感謝のメッセージ）・`ui.ts`・`format.ts` |

## 決まり

- 全画面に札「デモ用の架空データ」を出します（`shared/components/DemoBadge`、特典・演出の層は専用の札）。消しません
- 幅 375px で全部の操作ができ、ホームは幅 375px・高さ 667px と 812px で、スクロールなしに収まります（N-01・N-06）
- 操作する要素は高さ 44px 以上。色は `tokens.css` の値だけ（新しい色を足さない）
- 画面の操作は通信を待たずに見た目が変わります（N-21）。通信の成否で操作を止めず、エラーの画面は出しません
- 使わない語（`新しい口座を開く`・`口座開設`・`確約`・`参加`・`応援レース`・`応募資格`・`上位の体験`）は、文言ガードが検査します
- `shared/`・`styles/`・`core/` は、直さずに、コーディネーターに頼みます

## 差し替える所

| 何を | どこを |
| --- | --- |
| 感謝のメッセージの文（統括の採否で変わる） | `text/thanks.ts`（1 か所） |
| 推しの絵（縮めた版・先読みの順） | `art/registry.ts` の import と `PREFETCH_PLAN` |
| 公開 URL（11/18 の承認のあと） | `domain/share.ts` の `PUBLIC_URL`（1 か所） |
| コースの金額・枠・特典・預金の条件 | core の `data/courses.ts`（画面は読むだけ） |

## テスト

- `tests/unit/fan/`: ストアの順番と数字（U）。人物 15 通りの体験・文言の検査
- `tests/integration/fan/`: 画面（R）。共有の部品は本物、サーバーだけ偽物（`tests/helpers/fakeApi.ts`）
