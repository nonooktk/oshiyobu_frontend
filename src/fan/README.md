# src/fan/

ファン向け（`/fan/`。QR の行き先）。持ち主は F-2 です。人物（端末の番号から決まる 15 通り）の初めの値で、はじめの画面から始まります。

## 構成

| 場所 | 中身 |
| --- | --- |
| `App.tsx` | 殻。ページの切り替え・重ねる層・トースト・読み上げの領域・Esc。メニュー配下の画面と層は、`ChunkBoundary` で遅れて読む |
| `store/store.ts` | ストア（React の外に 1 つ）。状態と、申し込み・80% の演出・特典・感謝・共有・リセットの**順番**（タイマー）を持つ。通信はしない（`joinPerformance` を呼ぶだけ）。共有は、外のサイトを開かず、コピーもしない（どのボタンも、押すと投稿したことになるだけ） |
| `store/lifecycle.ts` | 閉じたら（pagehide・bfcache から戻ったとき）初めに戻す・最後の操作から 300 秒（`IDLE_RESET_SEC`）たったら初めに戻す。ひとり体験のときだけ動く |
| `store/FanProvider.tsx` | ストアと共有の部品（条件・共有メーター・連動）をつなぐ。reset の検知・「デモを最初に戻す」の受け口もここ |
| `domain/` | `state.ts`（状態の型と初めの値）・`view.ts`（人数・成立・次のアクションなど、画面が使う値）・`share.ts`（共有のボタンと投稿文）。数字・成立の判定は **core の関数だけ**を使う |
| `domain/heat.ts` | 開催熱量。人数の割合 → ゲージの長さ・段階（点火〜FEVER）・距離のことば。曲線（p の 2 乗）・境目（50%・70%・80%・成立）・名前は、ここ 1 か所。**画面に出すのは、ここが返す長さ・名前・ことばだけ**（人数・達成率・金額の数字は出さない。G-08） |
| `sound.ts` | 称賛の音（Web Audio の合成。素材ファイルなし）。鳴るのは、行動の直後と、段階の節目だけ。オフ・操作の前・使えない環境では、黙って何もしない。音のボタンは `components/SoundToggle.tsx`（全画面の上の帯） |
| `components/` | 最初に読む画面（はじめの画面・ホーム・メーター・次のアクション・演出・特典・感謝・共有のシート・絵の部品） |
| `pages/` | あとから読む画面（メニュー・応援コース・口座と預金・貢献・支援の状況・しくみ・推しと条件の変更・情報の扱い。設計 D-40 の `fan-pages`） |
| `layers/` | あとから読む層（やめる確認・引き継ぎ。`fan-layers`） |
| `art/registry.ts` | 推しの絵の置き場（1 か所）。丸い絵・大きい絵・コースのカードの切り抜き・特典の切り抜き。先読みの登録もここ |
| `prefetch.ts` | 先読みする絵と、遅れて読む塊を、共有の部品（`src/shared/prefetch.tsx`）に登録する |
| `text/` | 画面の文言。`voices.ts`（5 組のセリフ）・`thanks.ts`（感謝のメッセージ）・`ui.ts`・`format.ts` |

## 決まり

- **ひとり体験（既定）**: ファン向けは API を呼ばず、人数を端末の中だけで数えます（`VITE_SHARED_METER=on` のときだけ、共有メーター）。仲間を呼ぶと、その公演の最低人数に届く所まで一度に増えて、成立の演出が出ます（`domain/view.ts` の `friendsToClinch`。共有メーターありは 1 人ずつ）。閉じたら・5 分操作が無ければ、初めの状態に戻ります
- **ファン向けの画面に、人数・最低人数・残りの人数・達成率・目標の金額の数字を出しません**（G-08）。熱量（段階の名前・距離のことば・虹色の棒）で見せます。出してよい数字は、自分が払うコースの金額・預金・席数・日付・特典の n/3・ステップの 1 / 3 だけ。内部の数字（74 → 75 → 93）は、テストでは、画面の文ではなく、ストアの状態で確かめます。歯止めは `tests/integration/fan/no-numbers.test.tsx`
- 棒の色は、tokens.css の既存の色だけで作った虹（青 → 水色 → 緑 → 黄 → 橙 → 赤。緑と橙は `--success`・`--warning` の値を借りた）。長さが伸びるほど色が足されて、FEVER で全体が虹色になります
- 全画面に、札「動作確認用のデモ画面です」と札「デモ用の架空データ」を並べて出します（`shared/components/DemoBadge`、特典・演出の層は専用の札）。下から出るシート（やめる確認・引き継ぎ）は、枠（`SheetShell`）の見出しの行に札を置きます（後ろの画面が下へスクロールされていても見えるように）。消しません
- 幅 375px で全部の操作ができ、ホームは幅 375px・高さ 667px と 812px で、スクロールなしに収まります（N-01・N-06）
- 操作する要素は高さ 44px 以上。色は `tokens.css` の値だけ（新しい色を足さない）
- 書体は Corporate Logo Rounded Bold ver3（太さ 700 の 1 本。`tokens.css` の `:root[data-page='fan']` が `--font` を差し替える。`main.tsx` が `data-page` を付ける）。400 の指定の字も 700 の面で出るので、本文と見出しの区別は、太さでなく、大きさ・行間・色で付ける
- 文字の大きさは、`tokens.css` の段（`--fs-hero`・`--fs-figure`・`--fs-title`・`--fs-lead`・`--fs-body`・`--fs-note`）と行間（`--lh-*`）で決める。px を直書きしない（演出の中だけ別。`tests/unit/type-scale.test.ts` が検査する）。段の表は `docs/フォント.md` の「2. 文字の大きさの段」
- 画面の操作は通信を待たずに見た目が変わります（N-21）。通信の成否で操作を止めず、エラーの画面は出しません
- 使わない語は、文言ガード（`tests/unit/forbidden-words.test.ts`）が検査します。語の一覧は、そちらにあります
- `shared/`・`styles/`・`core/` は、直さずに、コーディネーターに頼みます

## 差し替える所

| 何を | どこを |
| --- | --- |
| 感謝のメッセージの文（統括の採否で変わる） | `text/thanks.ts`（1 か所） |
| 推しの絵（縮めた版・先読みの順） | `art/registry.ts` の import と `PREFETCH_PLAN` |
| コースの金額・枠・特典・預金の条件 | core の `data/courses.ts`（画面は読むだけ） |
