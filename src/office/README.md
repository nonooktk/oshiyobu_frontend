# src/office/

事務所向け（`/`）。持ち主は F-1 です（設計 D-34）。

## 構成

| 場所 | 中身 |
| --- | --- |
| `App.tsx` | 画面の組み立て。選んだ会場・費用・最低人数を、同じ端末のファン向けへ連動で渡す（`publishOffice`） |
| `store.ts` | 状態（メモリだけ）と操作の流れ（Zustand）。選択・入力の検査（core の `parseCost`・`parseMinPeople`）・「デモを最初に戻す」 |
| `view.ts` | 選んだ会場の判定（core の純関数だけ。画面の側で計算を書かない） |
| `scatter.ts` | 散布図の点（core の人数・種・偏りを使い、固定の種の乱数で置く） |
| `components/` | 上の帯・アーティスト・地図・会場・判定 3 点・条件を調整・提案の 1 枚・情報の扱い |
| `map/` | 地図の県の形（`shapes.ts`）・市の位置とラベルの向き・色の段（`layout.ts`） |
| `text/` | 文言（`labels.ts`）と 5 組の名前・頭文字・丸い絵（`artists.ts`）。文言は core の版に関係なく直せる |
| `office.module.css` | 画面の見た目（値は `tokens.css` の変数） |

## 決まり

- 数字は core から取ります。到達ライン・必要人数・見込み・札・上乗せ・達成率などの式を、画面の側で書きません
- 札は、必要人数で決まります（最低人数を変えても変わりません。決定 12）
- 全画面に札「デモ用の架空データ」を出します（`shared/components/DemoBadge`）。重ねて出す枠にも出します
- 通信しません（事務所向けは何も送りません）。`fetch` は使えません（ESLint が止めます）
- `shared/`・`styles/`・`core/` は、直さずに、コーディネーターに頼みます
