# src/presenter/

発表者用の画面（`/presenter/`）。持ち主は F-1 です。

- 合言葉つきのリセット（「リセットする」→ 確認の欄に `RESET`（大文字・半角・完全一致）→「実行する」の 2 段）と、接続の確認（`/healthz` の応答時間）だけです（仕様 SP-67）
- 結果は原因ごとに分けて出します（成功・合言葉が違う・合言葉が未設定または短い・応答がない・通信できない・予期しない応答）。文言は `text/page.ts`
- 合言葉は、画面の入力欄（`type=password`）に、実行のときだけ入れます。保存せず、成功したら欄からも消します。リポジトリ・文書・画面には書きません
- 聞き手の画面（事務所向け・ファン向け）から、この画面へのリンクやボタンを出しません。全ページに noindex が付いています
- 通信は `shared/meter` の `resetSharedMeter`・`checkApiHealth` を使います（ここから `fetch` は呼べません）
